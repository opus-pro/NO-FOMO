TrendRadar

TrendRadar is an open-source, lightweight, and easily deployable hot topic aggregation and intelligent notification assistant. It eliminates information overload by providing personalized news from over 11 mainstream platforms, including Weibo, Douyin, Zhihu, and financial news sources. Key functionalities include smart push strategies (daily summaries, current rankings, incremental monitoring), precise content filtering using custom keywords with advanced syntax, and dynamic trend analysis that tracks news hotness and evolution across platforms. A unique personalized algorithm prioritizes high-ranking and consistently appearing news. The system supports multi-channel real-time notifications via WeChat Work, Feishu, DingTalk, Telegram, Email, and ntfy, alongside multi-terminal adaptation through GitHub Pages and Docker. Version 3.0.0 introduced AI intelligent analysis, leveraging the MCP protocol for natural language queries and 13 analytical tools, enabling deep data insights, trend tracking, and summary generation. TrendRadar aims to empower users to proactively acquire desired information, suitable for investors, media professionals, and PR teams.

Agent Development Kit (ADK) for Go

The Agent Development Kit (ADK) for Go is an open-source, code-first toolkit designed for building, evaluating, and deploying sophisticated AI agents with enhanced flexibility and control. This modular framework applies established software development principles to AI agent creation, simplifying the design and orchestration of workflows ranging from simple tasks to complex multi-agent systems. While optimized for Google's Gemini models, ADK maintains model-agnosticism and deployment-agnosticism, ensuring broad compatibility across different AI models and deployment environments. The Go implementation of ADK is specifically tailored for developers creating cloud-native agent applications, capitalizing on Go's inherent strengths in concurrency, performance, and robustness. Its key features include an idiomatic Go design, a comprehensive tool ecosystem enabling agents with diverse capabilities, and a code-first development approach for maximum control, testability, and version management of agent logic. Furthermore, ADK facilitates the creation of scalable, modular multi-agent systems and offers strong support for containerization and deployment in cloud-native environments such as Google Cloud Run.
