Metis: Memory Foundation Model

To address limitations of external memory modules, researchers introduced Metis, the first prototype of a memory foundation model with native memory capabilities. Metis incorporates an evolving memory state directly within the model backbone, using memory attention to compress and retrieve historical context. Trained on large-scale memory-specific data with mid-training optimization objectives, its online memory maintenance is gradient-free and requires only a forward pass.
