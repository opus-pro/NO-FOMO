Mid-Harness verifies candidate actions before execution

Mid-Harness samples and verifies candidate actions between a terminal agent’s model and harness while leaving both unchanged. The authors report that a stronger verifier raises TMAX-9B Pass@1 on TerminalBench-Lite from 50.00% to 68.03% with eight sampled actions. Weak verification yields little benefit. The result suggests that choosing a safer action before it changes the environment can be a useful target for test-time compute, with verifier quality central to the gain.

02Sep 29

PivotOPD trains agents to avoid and recover from pivotal mistakes

PivotOPD combines preventive and recovery distillation for multi-turn agents. A teacher supplies a better action at a pivotal mistake and recovery actions for subsequent turns, addressing errors that alter the states an agent encounters. The authors report leading average results across their tested baselines and a 3.2-point SWE-Bench Verified improvement for a Nemotron-3.5 student. The practical lesson is to train recovery behavior explicitly, rather than learn only from successful trajectories.

03Sep 29

Agent Error Dataset turns failures into training evidence

The Agent Error Dataset contains 50,228 error-diagnosis pairs from 9,961 tasks across 33 environments, preserving traces and execution metadata for analysis. Its pipeline proposes corrections and checks them against evidence, including matched replay where supported. Across 3,062 replay pairs, the authors report verifier pass rates rising from 18.4% to 51.1% with first-proposal corrections. The resource makes failure analysis more concrete, although replay gains should not be confused with unrestricted deployment success.

False Frontiers diagnoses shared errors in self-evolving agents

False Frontiers examines co-cheating, where question proposers and solvers reinforce shared errors while internal rewards improve. Its CrossFit method separates source-document groups so feedback comes from a solver trained on the other group. The authors report reduced false agreement and improved downstream search performance for two model sizes. The result is a useful caution for self-improvement systems: agreement inside a training loop can increase without a corresponding rise in external correctness.
