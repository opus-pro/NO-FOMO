01Oct 6

AdvSim2Real trains web agents against adaptive prompt injection

AdvSim2Real co-evolves a task curriculum, an injection attacker and a web agent inside a frozen web world model. The researchers report that the resulting 4B agent improves task completion both with and without attacks, including against an unseen frontier-model adversary. Across 150 web tasks, completion under that adversary rises 33.6 percent relative to the base agent. The work addresses the gap between static injection defenses and attackers that adapt to a deployed model.

02Oct 5

UNREAL unifies corpus retrieval and long-context selection

UNREAL uses a frozen language model’s internal representations to encode chunks and derive retrieval queries, adding fewer than 500,000 trainable parameters. The authors evaluate the same selection mechanism for large-corpus retrieval and long-context inference. Reported HotpotQA recall increases from 49.1 to 73.2 percent, while long-context tests also improve after distractors are removed. The approach suggests that selecting useful evidence can be shared across retrieval and context processing rather than treated as separate systems.

03Oct 5

DAEDALUS builds agent memory through self-generated practice

DAEDALUS pairs an explorer that generates tasks with a solver that attempts them, converting failures into reusable heuristics. A heuristic enters the memory bank only after the solver repeatedly succeeds with it in context. The authors report mean success gains of up to 15.9 percentage points across their evaluations, without requiring existing tasks or oracle verifiers. The method targets repeated operational mistakes when agents encounter unfamiliar tools and environment conventions.

04Oct 5

SafeActBench examines whether agent actions follow established evidence

SafeActBench studies the gap between judging an action and executing an evidence-supported workflow. Across ten model and harness configurations, the researchers find that strong static assessment can coexist with weaker interactive behavior. The benchmark includes 656 cases in six operational domains and tracks when evidence was established relative to actions. Failures include stopping investigations early, acting before prerequisites are known and leaving dependent workflows incomplete, making execution discipline a distinct evaluation target.

05Oct 5

TRACE aligns FP4 training and rollout for reinforcement learning

TRACE addresses discrepancies between low-precision training and rollout paths in reinforcement learning for mixture-of-experts language models. It uses rollout-side quantization results to guide training-side rounding and caches selected quantization information to reduce overhead. Across four large MoE models, the authors report performance comparable to BF16 rollouts with up to 5.4 times faster rollout generation. The contribution concerns consistency across execution paths, not simply applying lower precision after a policy has already been trained.

06Oct 5

ALIVE teaches inserted video objects to interact with the scene

ALIVE targets video edits in which an inserted object must participate in the existing action, such as being picked up or manipulated. It trains on 35,800 editing pairs using an edited first frame and an instruction naming the object, with optional interaction guidance predicted by a vision-language model. The authors report improved interaction fidelity and source preservation. The work shifts object insertion toward coherent behavior over time rather than visual presence alone.
