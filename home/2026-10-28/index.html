EmbeddingGemma 2 unifies multimodal representations

EmbeddingGemma 2 is an open embedding model designed to represent text, images, audio, video, and their combinations in one shared space. Its authors report competitive performance against specialist models and substantially larger alternatives. The design supports selective encoder loading, adjustable vision token budgets, smaller embedding dimensions, and quantized weights. Those options make the paper relevant to multimodal retrieval systems that must balance quality against memory and inference budgets in constrained deployments.

03Oct 26

Agent interface changes can erase trained performance

This paper argues that trained agent policies absorb preferences from the prompts, tools, and control logic used during training. In a MiniWoB++ experiment, reversing observation-field order reduced success from 85.0% to 19.2%, despite leaving optimal decisions unchanged. The authors separate the opportunities offered by a harness from a policy's ability to use them. Their results caution that comparing interfaces with a fixed model can misjudge designs that would benefit from further training.

Nemotron diffusion research combines visual understanding and generation

Nemotron-Labs-Diffusion-Uni proposes a unified discrete diffusion language model for visual understanding and generation. 06Oct 26

MLE-World predicts experiment outcomes before execution

MLE-World fine-tunes a Qwen3.5-4B model to predict training logs, errors, and validation scores from code and a data description. A confidence estimate helps decide when a research agent should execute a candidate for real. On 17 MLE-bench Lite tasks, the authors report 77.9% agreement with held-out terminal outputs and up to 22.1% higher observed mean performance from guided search. The approach aims to reduce expensive experiment execution while retaining checks for uncertain predictions.

07Oct 24

Memory Tax questions the net value of agent memory

Memory Tax evaluates whether dedicated memory systems actually improve on retrieving directly from raw conversation history. Across multiple benchmarks and model backbones, the authors find that many memory approaches underperform simple retrieval in many settings. They distinguish the benefits of reorganizing information from losses caused by removing or obscuring evidence. The study recommends assessing the net contribution of memory rather than treating any structured memory layer as an automatic improvement for long-running agents.

08Oct 24

Higher reasoning effort does not guarantee better agent outcomes

A study across four benchmarks examines the cost and reliability of different reasoning-effort settings in proprietary and open-weight models. Higher effort can improve aggregate accuracy while still failing individual tasks solved at lower settings. For easy tasks solved at every level, the highest setting can cost up to 42 times more. The authors find that starting low and escalating after verified failure can match or improve fixed maximum effort, often at lower cost.
