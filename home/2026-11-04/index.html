ToolSpace builds agent environments from real tool dependencies

ToolSpace constructs training environments from dependencies observed in real MCP execution traces instead of inventing tools around synthetic databases. It retains task chains that can replay successfully and uses assertion-based checks. The authors report that harder benchmark variants reduce frontier-model scores by up to 38.2 points, while their training pipeline improves several open models. The result suggests execution-grounded environment design can strengthen long-horizon tool use, with the reported gains remaining specific to the evaluated models and benchmarks.

Research tests frequent compaction instead of long context

The paper You don’t need long context reports that frequent context compaction can preserve task accuracy across tested long-input and long-horizon workloads. It notes that later tokens can cost substantially more to generate and examines software-engineering agents taking at most one action per context. The authors use these findings to motivate semantic state space models. The study challenges assumptions about retaining every interaction, but its results should not be read as proof that long context is unnecessary for every task.

SpecPilot uses agents to optimize speculative decoding

SpecPilot uses an autonomous optimization loop to find deployment-specific improvements in speculative decoding. A cost model identifies bottlenecks, agents explore changes, and token-level checks compare outputs with the original system. Across the reported evaluation, single-request speedup over autoregressive decoding rises from 4.46 times to 10.87 times, with batching also improving. The authors report no quality loss in those tests; the results are tied to the evaluated models, drafters, hardware, and workloads rather than a universal serving guarantee.
