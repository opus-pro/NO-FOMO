01Nov 16

FastFrames targets interactive video generation latency

FastFrames proposes autoregressive video diffusion models designed for interactive latency. The authors identify VAE decoding and cache updates as major costs, then replace them with lighter alternatives. They report thirty-six milliseconds per frame for a 1.3-billion-parameter model on one B200 GPU and forty-five milliseconds for a fourteen-billion-parameter model on eight B200 GPUs. The work connects systems profiling with camera-conditioned and physics-conditioned video interaction, with results specific to the evaluated configurations.

CADMAGEDDON is an open-source agent that reconstructs editable CAD from meshes and can run on single-GPU systems or current-generation laptops. Integration with FreeCAD makes the output relevant to existing engineering workflows, particularly when proprietary parts need to remain within local infrastructure.
