OpenAI and Cisco launch Shirudo for live Linux defenses

OpenAI and Cisco introduced Shirudo, an open-source runtime for applying temporary protections to running Linux systems while permanent patches are prepared. It uses eBPF shields, signed deployment, and hardware-backed records, with operators controlling what gets deployed. In a controlled test, a Codex-generated shield blocked a Java4Shell exploit attempt against Elasticsearch without a restart. The project addresses the operational gap between discovering a vulnerability and safely rolling out a permanent fix.

Loop-PP schedules pipeline training for recurrent depth

Loop-PP redesigns pipeline scheduling and communication for models that revisit shared blocks multiple times. Conventional schedules assume an acyclic pass through stages, which creates ordering problems when later stages feed earlier ones. The authors report outputs bit-identical to a single-stage reference, peak-memory reductions of up to 32.8 percent, and best observed throughput gains of 12.7 percent on tested mixture-of-experts models. The work tackles a systems bottleneck behind growing interest in looped architectures.

SWE-Gym audit finds reward-label errors hurt coding-agent training

A systematic SWE-Gym audit finds that difficult coding tasks can be difficult for the wrong reason: their tests reject valid fixes. Among tasks a nine-billion-parameter base model never solved, the authors report false-negative tests in seventy-four percent. Repairing or removing problematic tasks improved held-out performance under matched comparisons. The released SWE-Gym-Verified contains 1,087 audited tasks with execution evidence, emphasizing that training rewards need validation beyond checking a single reference patch.

Embodied-Harness improves robot workflows without changing weights

Embodied-Harness separates robotic execution from reflection: an Actor operates the robot, while a Reflector turns observed successes and failures into reusable guidance. Hierarchical memory supports both immediate context and longer-term experience, without updating the underlying model parameters. The authors report improvements across several manipulation benchmarks and a 96.7 percent average on three real-world tasks. The narrow real-world test scope matters, but the framework illustrates how better operating procedures can complement stronger foundation models.

06Nov 22

Hindsight Twins corrects image errors without importing extra details

Hindsight Twins targets a failure mode in self-improving image models: a critic’s rewritten prompt can introduce unwanted lighting or scenery along with a useful correction. The method contrasts matched revisions containing the intended fix and the observed error, then distills their difference while anchoring to the original prompt. Across several image-model families, the authors report alignment improvements without increasing critic-induced bias, including continued gains over twelve rounds of self-training.

KernelShift tests coding agents against evolving CPU instructions

KernelShift evaluates whether coding agents can optimize real kernels as CPU instruction sets evolve. Its ninety-nine instances come from active repositories, including inference workloads. The authors report that agents beat auto-vectorized compiler output on established extensions and improve prefill speed in tested language models, but lag hand-tuned Arm kernels and struggle with unfamiliar matrix-tile programming.
