Agentic LongLive adds asynchronous memory to streaming video

Agentic LongLive separates a memory agent from a real-time video generator, maintaining text and image state for people, objects and scenes without reading generated video back into memory. The authors report stronger identity and scene consistency on a 25-story benchmark, with about one percent additional generation time on H100. 02Nov 24

SPLICE learns from agent rollouts that all fail

SPLICE targets a failure mode in group-based reinforcement learning: when every long-horizon rollout fails, relative rewards offer no useful learning signal. A proposal model inserts bounded alternatives into current-policy trajectories, then evaluates them through learner continuations. The authors report gains of 2.8 to 9.8 percentage points over GRPO across software-engineering and deep-research settings. The approach seeks useful local supervision without requiring expensive complete solutions from a stronger model.

SPARC uses geometry to prune video attention and preserve scenes

SPARC uses geometry-guided attention pruning to connect camera control with persistent scene memory in video diffusion transformers. Observed regions attend to corresponding historical tokens, while unseen regions retain dense attention for synthesis. The authors report improved camera adherence and scene revisitation without adding separate learnable control or memory modules. Their reported speedup exceeds fifty times when combined with four-step distillation, so that figure reflects the combined setup rather than pruning alone.

RoboEvo2 couples robot policies with evolving agent tools

RoboEvo2 alternates between improving an agent harness from policy failures and training the policy on verified successful trajectories. Reusable skills, routing strategies and memory support the first direction, while supervised learning and preference distillation support the second. CARE-OPD reduces the cost of training long-horizon agents

CARE-OPD improves on-policy distillation by collecting histories that include student mistakes and allocating replay to consequential decisions. Confidence gating filters unreliable teacher responses, while downstream evidence determines which turns deserve more training. On SWE-bench Verified, the authors report 59.5 percent success with 45 percent less training time and 44 percent fewer environment actions than asynchronous online distillation. The result connects better coverage of agent behavior with more efficient use of expensive interaction data.

AIChipBench exposes hidden state errors in agent-designed hardware

AIChipBench evaluates coding agents implementing language-model decoders in synthesizable hardware descriptions. It tests stored state as well as outputs, because a wrong update may only corrupt later tokens. Across thousands of attempts, the authors find that feedback identifying the first state mismatch improves acceptance substantially. Many previously accepted designs fail broader retesting. The benchmark emphasizes that passing development cases is insufficient evidence of correctness for stateful accelerator designs or subsequent performance optimizations.
